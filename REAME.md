# PocketSmart AI 💡
Your Smart Budget & Recommendation Engine

## Project Description
PocketSmart AI is a lightweight web application designed to track monthly expenses, calculate remaining budgets, and provide intelligent budget allocation recommendations.

## Tech Stack
- **Backend:** FastAPI (Python)
- **Data Validation:** Pydantic
- **Frontend:** HTML5 / CSS3

## Features
- FastAPI initialization with modular architecture setup.
- Budget calculation and remaining balance status API endpoints.
- Simple web dashboard interface (`index.html`).

## How to Run
1. Install dependencies:
   `pip install -r requirements.txt`
2. Start the FastAPI server:
   `uvicorn app.main:app --reload`
